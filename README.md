# 은석 연화법당 3D (시안)

연화 어린이회 어린이들이 크롬북·PC 브라우저에서 들어와 볼 수 있는 3D 온라인 법당 시안입니다.

- 법당 안을 걸어 다니며 삼귀의·어린이오계, 연등 달기, 공양 올리기, 팔정도 디딤돌 도장을 해 볼 수 있어요.
- 팔정도 문구 카드와 같은 내용이 매주 자동으로 순환하고, 기념일에는 법당 모습이 바뀌어요.
- 연이(마스코트)가 계절에 따라 옷을 바꿔 입어요.

## 시안이라서

- 반 대항 연꽃 숫자 등은 **예시**예요.
- 연등·도장·절 기록은 **그 기기의 브라우저에만** 저장돼요. 전교 기록을 한곳에 모으려면 공유 저장이 따로 필요해요.

## 파일

- `index.html` — 페이지 전체(법당 사진 3장 포함, three.js r128은 cdnjs, 글꼴은 Google Fonts에서 불러옴)
